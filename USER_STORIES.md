# User Stories — Дневник тренировок

## US-01 — Добавление упражнения

**Как пользователь**, я хочу добавлять новое упражнение в каталог,
**чтобы** использовать его при создании тренировок.

### Критерии приемки:
- Можно указать название упражнения.
- Можно выбрать мышечную группу.
- Упражнение появляется в каталоге.

---

## US-02 — Просмотр упражнений по мышечным группам

**Как пользователь**, я хочу просматривать упражнения по мышечным группам,
**чтобы** быстро находить нужное упражнение.

### Критерии приемки:
- Упражнения разделены по мышечным группам.
- Можно выбрать нужную мышечную группу.
- Отображаются упражнения выбранной группы.

---

## US-03 — Создание тренировки

**Как пользователь**, я хочу создавать тренировочную сессию с названием и датой,
**чтобы** сохранять информацию о своих тренировках.

### Критерии приемки:
- Можно указать название тренировки.
- Дата тренировки сохраняется.
- Созданная тренировка появляется в истории.

---

## US-04 — Добавление упражнения в тренировку

**Как пользователь**, я хочу добавлять упражнения в тренировочную сессию,
**чтобы** формировать состав своей тренировки.

### Критерии приемки:
- Можно выбрать упражнение из каталога.
- Выбранное упражнение отображается внутри тренировки.
- В одной тренировке можно использовать несколько упражнений.

---

## US-05 — Фиксация подхода

**Как пользователь**, я хочу записывать номер подхода, рабочий вес и количество повторений,
**чтобы** сохранять результаты выполнения упражнения.

### Критерии приемки:
- Указывается номер подхода.
- Указывается рабочий вес.
- Указывается количество повторений.
- Данные сохраняются внутри выбранного упражнения.

---

## US-06 — Просмотр истории тренировок

**Как пользователь**, я хочу просматривать предыдущие тренировки,
**чтобы** отслеживать свою тренировочную историю.

### Критерии приемки:
- Отображается список сохраненных тренировок.
- Для тренировки отображается дата и название.
- Можно открыть тренировку и посмотреть упражнения и подходы.

---

## US-07 — Определение личного рекорда

**Как пользователь**, я хочу видеть максимальный вес для конкретного упражнения,
**чтобы** отслеживать свой личный рекорд.

### Критерии приемки:
- Система анализирует сохраненные подходы.
- Определяется максимальный зафиксированный вес.
- Результат отображается для выбранного упражнения.

---

## US-08 — Расчет тоннажа

**Как пользователь**, я хочу видеть суммарный тоннаж тренировки,
**чтобы** оценивать общий объем выполненной работы.

### Критерии приемки:
- Для каждого подхода учитываются вес и количество повторений.
- Рассчитывается общий тоннаж тренировки.
- Результат отображается пользователю.

---

## US-09 — Отслеживание прогресса

**Как пользователь**, я хочу сравнивать рабочие веса в разные даты,
**чтобы** отслеживать изменение своих результатов.

### Критерии приемки:
- Система использует данные предыдущих тренировок.
- Можно увидеть рабочие веса по датам.
- Пользователь может сравнить результаты между тренировками.

---

## US-10 — Профиль пользователя

**Как пользователь**, я хочу указывать свой текущий вес и тренировочную цель,
**чтобы** хранить основные параметры своего профиля.

### Критерии приемки:
- Можно указать текущий вес.
- Можно указать цель тренировок.
- Данные профиля сохраняются.

---

## US-11 — Сохранение данных

**Как пользователь**, я хочу сохранять историю тренировок в локальное хранилище,
**чтобы** данные не терялись после закрытия приложения.

### Критерии приемки:
- История тренировок сохраняется.
- Данные профиля сохраняются.
- После закрытия приложения данные не теряются.

---

## US-12 — Загрузка данных

**Как пользователь**, я хочу загружать сохраненные данные при запуске приложения,
**чтобы** продолжать работу с предыдущего места.

### Критерии приемки:
- При запуске загружается профиль пользователя.
- Загружается история тренировок.
- Загружаются упражнения и подходы.
