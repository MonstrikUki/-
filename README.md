Мы группа разработчиков, объединенных общей целью: создать
**«Дневник тренировок»** — приложение для удобного ведения истории
тренировок, фиксации подходов и отслеживания прогресса.

## Наш проект

**Дневник тренировок** позволяет пользователю:

- хранить каталог упражнений;
- создавать тренировочные сессии;
- записывать подходы, вес и повторения;
- отслеживать личные рекорды;
- рассчитывать тоннаж тренировок;
- анализировать прогресс;
- сохранять историю тренировок.
